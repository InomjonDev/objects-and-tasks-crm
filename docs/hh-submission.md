# Сообщение для hh.ru

Здравствуйте! Подготовил мини-CRM «Объекты и задачи».

Приложение: https://objects-and-tasks-crm-one.vercel.app
Репозиторий: https://github.com/InomjonDev/objects-and-tasks-crm

Перед отправкой добавьте доступы постановщика и двух исполнителей из локального файла `.local/demo-accounts.json`. Готовое сообщение с доступами находится в игнорируемом файле `.local/hh-submission-private.md`. Пароли не публикуйте в репозитории.

В приложении есть объекты, задачи, назначение исполнителей, полный цикл проверки и история статусов. Ограничения доступа и переходов выполняются в базе данных, включая запросы в обход интерфейса. Удаление сохраняет историю. В демонстрационной базе три объекта и задачи во всех пяти статусах.

В репозитории приложены миграции, инструкции запуска, объяснение для руководителя (`docs/manager-explanation.md`), решения и допущения (`docs/decisions.md`) и результаты проверок (`docs/verification.md`).

Готов показать результат и объяснить решения на созвоне.
